# Deadline Defender — Continuance Vault

A case-manager operating system for eviction defense, housing stability, medical casework, and benefits recertification in Washington.

## What this build is

- Dual-rail shell: **Command** (work) and **Washington desk** (authority + filing)
- People-first caseload across four practice lanes
- Date constellation with notification channels (court / client / counsel / agency)
- Safety vault of sealed folios
- Washington instruments that fill captions, parties, RCW citations, and **highlight every name in copper**
- Submit path to King County eFile and Sheriff Civil (writ stays)

## Hierarchy of work

1. Keep the person housed today
2. Hit the written deadline
3. Seal a complete vault folio
4. Hand the court a ready order

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind 4 · Framer Motion · Groq (optional polish)

## Run

```bash
npm install
npm run dev
```

Generated pleadings are **advocate drafts for licensed review**. They are not a substitute for a lawyer and should be checked against the current RCW, local rules, and the client's file before filing.
