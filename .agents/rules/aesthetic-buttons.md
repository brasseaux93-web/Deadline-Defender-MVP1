# Tactical Button Interactions

Strictly prohibit the use of magenta, fuchsia, or bright pinks across all interactive elements and button states (including `:hover`, `:focus`, `:active`, and pressed).

For any pushed or active button states, maintain the tactical, dark obsidian aesthetic. Simulate depth using an inset shadow and a subtly darkened background. 

If an active state or focus ring requires an accent color, utilize a muted gold (e.g., `#B79A61`) or a low-opacity glassmorphic overlay to ensure the UI remains cohesive and free of harsh neon hues.
